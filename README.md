# COR Web Solutions

Custom websites for local businesses, with optional monthly SEO.

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Add a Resend API key in `.env.local` before testing the contact form. See [BASICS.md](./BASICS.md) for brand, pages, SEO, and deploy notes.
